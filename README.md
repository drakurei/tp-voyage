# TP Voyage

Site de présentation de destinations de voyage, réalisé avec React et React Router dans le cadre d'un TP.

Site en ligne : https://drakurei.github.io/tp-voyage/

## Pages

- **Accueil** : présentation du projet
- **Destinations** : liste des pays avec un lien vers chaque fiche
- **Détails** : description, capitale, région et quelques photos du pays
- **À propos**
- **404** : page affichée pour une adresse inconnue

## Technologies

- React
- React Router
- React Bootstrap
- Vite

## Installation

```bash
npm install
npm run dev
```

## Déploiement

```bash
npm run deploy
```

Le site est publié sur GitHub Pages depuis la branche `gh-pages`.

## Arborescence

```
src/
  components/   Navbar
  data/         destinations
  layouts/      MainLayout
  pages/        Accueil, Destinations, Détails, À propos, Recherche, 404
  router/       Router
```
